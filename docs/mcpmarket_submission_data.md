### Full Description
```
TaskChampion MCP is a Model Context Protocol server for Taskwarrior 3.x, TaskChampion, and Timewarrior. It provides 35 tools for complete task lifecycle management, including:

- Task CRUD operations (create, read, update, delete, complete, undo)
- Schema-based validation with 5 bundled presets (minimal, GTD, scrum, kanban, custom)
- Role-based permissions (CONTRIBUTOR/GENERATOR/MANAGER)
- Timewarrior integration for time tracking
- Runtime reload without IDE restart
- Subtasks, batch operations, and bulk modifications
- Comprehensive security controls and rate limiting

Perfect for terminal power users who want LLM assistance with task management and time tracking.

Install: pip install taskchampion-mcp or uvx taskchampion-mcp
License: Apache-2.0
Python: 3.10+
```
