---

## Changes

### Changed

**18 tool descriptions rewritten for agent clarity** (PR #44)

Every tool description now covers six dimensions required for reliable agent
use:

1. Read-only vs mutation disclosure — every read-only tool says so; mutation
   tools disclose atomicity, confirmation flow, and role requirement.
2. `dry_run` semantics — explicitly documented where supported.
3. Parameter intent — non-obvious parameters explained beyond the schema
   (e.g. `project_dir`, `period` syntax, `confirm_token` flow, tags formats).
4. Distinction from sibling tools — explicit "prefer X over Y when Z" guidance.
5. Usage guidance — when to use, when not to, what alternatives exist.
6. Error conditions — what the tool returns when dependencies are missing
   (e.g. Timewarrior not installed, sync server not configured).

Tools updated: `propose_initialization_options`, `generate_initial_schema_preview`,
`list_tasks`, `get_task`, `search_tasks`, `annotate_task`, `start_task`,
`stop_task`, `get_projects`, `get_tags`, `get_active_context`, `get_task_report`,
`get_time_summary`, `get_time_status`, `batch_create_tasks`, `undo_last_action`,
`sync_tasks`, `bulk_modify`.

**Glama score badge added to README** — renders the live quality score on the
GitHub repo page.
