## Install

```bash
uv tool install taskchampion-mcp
# or ephemeral:
uvx taskchampion-mcp
```

Neovim / Claude Code CLI:

```bash
claude mcp add taskchampion -- uvx taskchampion-mcp
```

See per-target guides under [`docs/manuals/targets/`](../manuals/targets/).

## Scope

- Four primary **stdio** targets: Claude Desktop, Windsurf, Cursor, Neovim (via Claude Code CLI)
- 26-scenario per-target acceptance matrix
- Runtime reload (ADR 19), capability introspection (ADR 21a)
- Published via GitHub Actions [`publish.yml`](../../.github/workflows/publish.yml)

HTTP/SSE transport and ChatGPT/Codex targets are **v1.x** work.
