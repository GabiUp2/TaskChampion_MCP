## Apigene Research Findings

**Status:** NOT ELIGIBLE for submission

**Reason:** Apigene's Official MCP Directory only lists "vendor-verified official servers" from companies like GitHub, Salesforce, Google, etc. Their criteria:

- Server must be maintained and verified by the actual vendor/company
- Must be hosted on the vendor's official domain (e.g., mcp.github.com, mcp.salesforce.com)
- Must have direct vendor support and comprehensive documentation
- Community-maintained servers are not listed

**TaskChampion MCP Status:** As a community project (not from an official vendor like Taskwarrior/GothenburgBitFactory), it does not qualify for Apigene's "official" directory.

**Alternative:** Consider Apigene's potential community directory (if they add one in the future) or focus on other marketplaces that accept community submissions.
